# Symmetries of a tree

An interactive page for MATH 25700 (Honors Basic Algebra I, University of Chicago, Autumn 2026): the symmetries of binary trees with 4, 8 and 16 leaves, and the cyclic rotations of a ternary tree with 9 leaves. Each is a Sylow p-subgroup of the symmetric group on the leaves (orders 2^3, 2^7, 2^15 and 3^4). Click a vertex to turn the part of the tree below it.

Live page: https://j2d9w5xtjn-png.github.io/math25700-tree-symmetries/ (deep links `#4`, `#8`, `#16`, `#9`).

The page is a single self-contained HTML file, `index.html`.
